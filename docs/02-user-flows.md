# 02 用户流程（User Flows）

- 版本：v1.2（方案稿，退回修订中，待技术负责人第三次复审）
- 状态：**未获批准。**

本文定义管理员与作者两类角色的完整操作流程、页面清单，以及每个页面的输入、输出与异常状态。页面命名与 `03-data-model.md` 对象一一对应。

---

## 1. 全局约定

- 所有写操作、读操作均经服务端鉴权；作者的数据隔离在**服务端**完成，前端隐藏仅作体验优化，不构成安全边界。
- 统一错误码与提示：`401 UNAUTHORIZED`（未登录）、`403 FORBIDDEN`（越权）、`404 NOT_FOUND`（不存在或不可见）、`409 CONFLICT`（并发/状态冲突）、`422 UNPROCESSABLE`（校验失败）、`429 RATE_LIMITED`（限流）、`500 INTERNAL`（服务端异常，前端展示"系统错误 + 请求 ID"，不暴露堆栈）。
- 所有生成类操作异步返回 `task_id`，前端轮询任务状态。
- 生成类操作在页面顶部统一展示"进行中"进度条，禁止重复提交（按钮置灰 + request_id 幂等兜底）。

## 2. 管理员流程

### 2.1 登录

**输入**：邮箱、密码。
**输出**：成功进入管理后台；失败提示错误类型。
**异常**：账号停用 → `403`"账号已停用，请联系管理员"；连续失败 → 锁定提示；首次登录未改密 → 跳转改密页（由 `must_change_password` 布尔控制）。

### 2.2 创建作者账号

**输入**：邮箱、初始密码（或自动生成）。
**输出**：一次性展示初始密码（仅此一次，之后不可回看）；账号进入"已创建/待首次登录"状态。
**异常**：
- 邮箱重复 → `409`"该邮箱已存在"。
- 账号总数（含停用）已达 10 → `422 ACCOUNT_LIMIT_REACHED`"账号数量已达上限（10）"；并发创建由事务锁保证不突破。
- 密码不符合策略 → `422` 提示具体策略。
- 展示初始密码后刷新页面 → 密码不可再次查看，只能重置。

### 2.3 重置密码 / 停用 / 启用账号

**输入**：目标账号 + 操作类型（重置需新初始密码）。
**输出**：重置成功（新密码一次性展示）；停用后该账号会话立即失效；启用后账号恢复登录能力。
**异常**：若管理员试图停用唯一的管理员账号 → 拒绝并提示"至少保留一个管理员"。

### 2.4 系统配置

**输入**：模型供应商 base_url、模型名、并发生成上限（≤2）、单次生成字数上限、单章上下文召回条数上限、**每日 Token 预算上限、单任务 Token 硬上限**。
**不包含 API Key**：Key 仅由环境变量/Docker secret 注入，页面只展示**"已配置 / 未配置"状态**，并提供**"测试连接"**按钮，不提供输入/保存 Key 的入口。
**输出**：配置保存；非敏感配置回读。
**异常**：模型未配置 → "未配置"状态 + 测试连接失败提示；并发上限设 >2 → 拒绝（按 `00` §3.3 硬约束）；配置生效需重启 Worker 时给出明确提示。

### 2.5 任务与用量视图

**输入**：时间范围、作者筛选。
**输出**：任务列表（状态、类型、耗时、Token 数）、按作者聚合的成本估算、失败任务错误摘要。**不含正文内容。**
**异常**：无数据 → 空态；成本估算无法与账单对齐（>10%）→ 标记"待核对"。

### 2.6 运维视图（仅元数据，默认不含正文）

**输入**：选择某作者某作品。
**输出**：只读查看作品结构（标题、章节数、状态）、任务、Token 用量、错误摘要。**不展示章节正文**。
**异常**：界面顶部恒定标注"运维元数据视图 · 不含正文"；无任何正文读取入口。

### 2.7 正文临时查看（仅排障，全程审计，作者批准）

**输入**：管理员发起"正文查看授权"请求（填写事由 + 范围 + 时长）。
**批准**：**由作品作者批准（默认）**；若采用管理员自批，须由负责人决策并记录（见 `06` Q13）。
**输出**：获批后获得有时效（默认 1 小时）与范围（限定作品/章节）的授权；每次查看写入审计日志（who/when/what/why）。
**异常**：未授权直接请求正文接口 → `403`；授权过期 → 重新发起；**越范围读取 → `403`**；审计日志不可缺失、不可篡改。

### 2.8 备份与恢复演练

**输入**：触发备份 / 触发恢复演练。
**输出**：备份文件路径与校验和；恢复演练结果报告。
**异常**：备份失败 → 错误 + 日志；恢复演练发现数据不一致 → 高亮告警。

## 3. 作者流程

### 3.1 登录与改密

同管理员，但登录后进入"我的作品"，且**看不到任何管理入口**。

### 3.2 新建作品

**输入**：标题、简介、题材（固定"玄幻升级"）、目标章节数、单章字数目标。
**输出**：作品创建成功，进入设定向导。
**异常**：标题为空/重复（同作者内）→ `422`；题材无其他选项。

### 3.3 设定向导（分步）

**步骤与输入**：
1. **作品方向**：子类型（仙侠/修真/异世/洪荒）、核心金手指、语气风格、主角一句话定位（**题材参数，由规则包 field_schema 驱动，存 work_settings**）。
2. **世界**：大陆/位面结构、势力分布、灵石经济、地理。
3. **人物**：主角 + 配角 + 反派；每人含姓名、身份、性格、目标、秘密、初始境界、所属势力。
4. **境界体系**：层级列表（每层：名称、小境界数、突破条件、寿命、战力基准）。
5. **势力**：名称、类型、层级、驻地、实力评级、敌友关系。
6. **物品/资源/功法**：法宝与物品、灵石等资源初始量、功法能力。

**输出**：设定保存成功，条目进入设定库；向导可跳过（允许先建作品后补设定），但生成正文前强校验"最小设定集"（至少主角 + 境界体系 ≥3 层）。
**异常**：跳过向导直接点"生成卷纲" → 提示缺失最小设定集；字段超长 → `422`；境界层级被人物引用后删除 → 拒绝并提示引用处。

### 3.4 生成卷纲 → 十章阶段目标 → 章节细纲 → 场景节拍

**输入**（各步）：确认或编辑上一级产物；必要时回填设定。
**输出**：各步产物落库，可编辑；每步均能查看"生成时使用了哪些设定/历史"（上下文来源）。
**异常**：
- 生成任务失败 → 产物不落库，任务标 `failed`，展示错误摘要与重试按钮。
- 重复点击 → 幂等，不产生多份（返回同一 task）。
- 作者中途编辑了细纲再生成正文 → 提示"细纲已修改"，需确认。

### 3.5 生成正文草稿 → 候选区 → 采纳 / 放弃

**输入**：点击"生成正文"（可多次生成，产生多个候选）。
**输出**：草稿进入**候选区（chapter_candidates）**，多个候选并存；作者预览后可"采纳"（转为正式版本，事务分配版本号）或"放弃"（候选标记废弃）。
**异常**：
- 生成结果 <1200 字 → 视为失败，不写候选表，任务 `failed`。
- 生成中断/模型 502 → 任务 `failed`，正式版本**不受影响**。
- 重复采纳同一候选 → 幂等，返回已分配的版本号，不重复产生正式版本。
- 采纳已放弃的候选 → `409` 拒绝。

### 3.6 人工编辑 → 保存版本

**输入**：Markdown 编辑正文。
**输出**：保存产生新版本（作者 `human`），版本号递增。
**异常**：正文为空保存 → 拒绝；编辑不触发模型调用（断网仍可编辑本地草稿）。

### 3.7 玄幻一致性检查

**输入**：点击"检查本章/全卷"。
**输出**：7 类问题清单（境界/战力/资源/物品/认知/时间线/伏笔），每条含严重级、原文证据、建议位置。
**异常**：无问题 → 提示"未发现一致性问题"；规则包缺失 → 明确报错不静默通过。

### 3.8 局部重写 → 应用

**输入**：选中段落范围 + 重写指令。
**输出**：生成替换文本 → 预览 → 应用后产生新版本，未选段落不变。
**异常**：未选段落被改动 → 判定为失败（见 `04` 用例 AT-RW1）。

### 3.9 事实提取与确认（最终版本确定后，v1.2 明确顺序）

**前置**：章节已有**最终正式版本**（生成→编辑→局部重写均已完成）。
**输入**：点击"提取事实"（在最终版本上触发）。
**输出**：候选事实列表，每条含**自然语言描述 + 结构化影响（fact_effects：目标实体、路径、old/new/delta）**、来源版本、原文证据。
**操作**：作者逐条"接受"或"拒绝"；可先修正结构化影响再确认。
**异常**：
- 回写失败 → 整体回滚，事实与人物/资源/设定状态一致，无半写。
- 重复回写 → 幂等，不产生重复状态变更。
- **正文版本变更 → 已接受事实自动标记 stale**，需重新提取确认。
- 待确认事实不阻塞下一章生成（默认），但列表顶部提示"有 N 条事实待确认"。

### 3.10 版本历史 / 恢复 / 对比

**输入**：进入章节版本历史。
**输出**：版本列表、任意两版 diff、恢复按钮。
**异常**：恢复后版本链完整，历史版本不删除。

### 3.11 导出作品

**输入**：选择格式（Markdown / 文本 / Word）。
**输出**：合并稿 + 卷纲 + 设定附录；单章导出含细纲与版本号。
**异常**：导出中服务重启 → 重新导出即可，不残留半文件；Word 导出在许可证确认前置灰不可用。

## 5. 关键异常状态汇总（贯穿所有页面）

| 异常 | 触发条件 | 系统行为 | 用户可见结果 |
| --- | --- | --- | --- |
| 越权访问 | 作者请求他人作品 | 服务端 `403` | 提示无权访问，不返回任何他人数据 |
| 并发冲突 | 同章节并发编辑 | `409` + 版本号 | 提示刷新后重试 |
| 重复提交 | 重复点生成 | request_id 幂等去重 | 不产生多份记录 |
| 生成失败 | 模型超时/502 | 任务 `failed`，正文不落候选/正式 | 错误摘要 + 重试 |
| 服务重启 | 运行中任务中断 | 任务状态持久化恢复 | 任务可见（失败/待重试） |
| 半写状态 | 事务回滚 | 正文与状态一致 | 无"写了一半"的章节 |
| 事实回写失败 | 接受事实后回写异常 | 整体回滚 | 事实/状态/设定一致，无半写 |
| 超预算 | 触发每日预算或单任务 Token 上限 | 拒绝/中止任务 | 明确提示，不静默继续 |
| 正文越权 | 管理员未授权读正文 | `403` | 提示需临时授权 |
