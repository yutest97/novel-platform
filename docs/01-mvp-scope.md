# 01 第一版范围（MVP Scope）

- 版本：v1.0（方案稿，待技术负责人审查）
- 状态：**未获批准。**

---

## 1. 优先级定义

| 级别 | 含义 | 判定 |
| --- | --- | --- |
| **P0** | 缺失则第一版无法验证核心目标 | 缺任意一项 → 阶段验收直接不通过 |
| **P1** | 影响可用性与体验，但不阻断核心验证 | 允许在第一版内迭代补齐，需给出替代手工路径 |
| **P2** | 明确不做 | 列入"不做清单"，不排期 |

优先级由**产品目标反推**（见 `00` §2.1），而非技术实现顺序。

## 2. 功能清单（含优先级与验收标准）

### 2.1 账号与权限

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-AUTH-01 | 管理员创建作者账号（邮箱 + 初始密码） | P0 | 创建返回账号 ID；初始密码一次性展示且仅管理员可见、不落日志 |

| F-AUTH-03 | 管理员重置密码 / 停用 / 启用账号 | P0 | 停用后该账号全部会话立即失效（服务端逐请求校验，非等 token 过期） |

| F-AUTH-05 | 密码策略（≥10 位、含大小写与数字；argon2id 哈希） | P0 | 库中无明文/可逆密文 |

| F-AUTH-08 | 管理员修改自己密码 | P1 | 改后其余会话失效 |

## 3. 不做清单（P2，明确排除）

1. 公开自主注册 / 邀请码自助兑换
2. 支付、充值、会员、订阅、推广
3. 多人实时协作 / 评论
4. 社区、排行榜、推荐流
5. 手机 App
6. 语音、音乐、视频生成
7. 自动发书到第三方平台
8. 模型训练 / 微调
9. 大规模爬虫
10. 同时开放多个题材（第一版仅玄幻）
11. 复杂多 Agent 自由对话
12. 邮件/短信自助找回密码、第三方 OAuth、企业 SSO
13. PDF/EPUB 导出、网页发布
14. 跨作品检索 / 全局搜索（隔离边界，见 `00` §6.1）
15. Redis / Kubernetes / 微服务（架构约束，见 `05`）

## 4. 验收标准汇总（阶段验收口径）

- P0 全部功能满足其"验收标准"列 → 阶段功能验收通过。
- 一致性、持久化、幂等等**跨功能硬性要求**由 `04-acceptance-tests.md` 用例覆盖，与本节并列判定。
- 任何"用以后可扩展代替当前明确边界"的写法，均视为未完成（对应 `00` §6.1 硬边界）。
